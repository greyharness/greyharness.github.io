work

I test an industrial maintenance app, Android tablet and web. Started out testing by hand, then built the automation around it.

  • End-to-end suite across web and mobile in Python and pytest. Create on web, complete on the tablet, check it back on web.
    1,500+ recorded runs
  • Test IDs added to the app's source so tests stop breaking every release, plus an audit that flags anything missing one.
  • Emulator rig that runs the tests and says whether a failure was the app, the test or the setup.
  • Dashboard that picks up tickets ready for QA, runs the matching test five times and posts the result on the ticket.
  • Red-team testing on an AI assistant. Got data out of it that a low-level user shouldn't see, and wrote up how.

That code belongs to the company, so it isn't public.
